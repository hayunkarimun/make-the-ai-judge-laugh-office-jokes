One line about office life, under 200 characters. `main.ts` (Node 22, stdlib
only) scores six candidate jokes against the judge brief — real joke,
unexpected turn, rings true about the office, tight wording, fresh take —
and writes the winner to `/output/entry.txt`.

The winning line:

> HR said our open-plan office encourages collaboration. It mostly encourages headphones.

Run it with `MAKEFUN_OUTPUT_DIR=/tmp/out node main.ts`.
